# Archery Arena (तीरंदाज़ी अरेना)

A first-person bow-and-arrow browser game. Single `index.html`, no build step.

- 300 levels: still targets, moving targets, spinning boards, fruit slicing
- Wind, breath-hold, draw power, unlockable bows
- Progress saved in the browser (localStorage)

Deploy: import this repo in Vercel, framework preset "Other", no build command.
